# hxyfront-62004 雪板交付封存台

面向滑雪板调校店的交付封存前端：维护工单只有在**底板损伤全部修补完成**且**刃角复核通过**后，登记取板联系人与到场日才能进入封存位；封存后任何改动都会触发退回流程，取板需核对封存码。

## 业务规则

- **封存准入**：损伤修补完成 + 刃角复核通过 + 取板联系人 + 到场日，缺一不可。
- **整单拒绝**：封存位不足，或同一客户已有"封存未取"工单时，申请直接拒绝，原工单与封存位占用保持不变。
- **退回释放**：封存后新增损伤、改动刃角（复核自动清零）或把损伤标回未修，工单立即退回修补、封存码作废、封存位释放，全部动作写入操作记录。
- **取板**：凭封存码核对，码不符拒绝；核对通过后释放封存位，工单转为"已取板"并保留全部记录。
- **超期催取**：到场日已过仍未取板自动显示为"催取中"（红色封存位），记录与封存位保留，到场后仍可凭码取板。
- 板型/状态筛选、封存位实况、客户历史（工单总数 / 封存未取 / 已取板）随数据实时同步。
- 数据只保存在浏览器 `localStorage`，刷新后保留；页面提供"恢复示例数据"。

## 文件结构（规则 / 状态 / 界面三层分离）

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 业务规则层：状态推导、封存准入、整单拒绝、退回释放、取板核对，均为纯函数，失败时返回错误而不产生新状态 |
| `src/store.ts` | 状态层：`useWorkbench` 维护工单与封存位唯一数据源，封装动作并持久化到 `localStorage`，内置示例数据 |
| `src/App.tsx` | 界面层：指标、筛选、封存位实况、工单卡片（损伤/刃角/封存/取板/操作记录）、客户历史表 |
